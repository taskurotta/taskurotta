Состояние — одно из четырёх (слово + дата, при PENDING и CLOSED — что именно):
- `ANALYZING (YYYY-MM-DD)` — запрос зафиксирован, над ним работают;
- `PENDING (YYYY-MM-DD, ждём: <кто, что>)` — ждём ответ/событие;
- `READY (YYYY-MM-DD)` — всё проработано, готовы пустить в работу, но ещё не пустили;
- `CLOSED (YYYY-MM-DD, <причина: не нужен / неактуален / ушёл в работу>)` — после CLOSED папка переезжает в `docs/requests/archive/`.
