# L1: System Context — taskurotta

## Что это
taskurotta — фреймворк для координации работы распределённых компонентов (определение из README проекта). Открытый исходный код, лицензия MIT.

## Место системы в мире
- **Серверные ноды**: экземпляры taskurotta, развёрнутые как отдельные контейнеры (docker-compose: `tsk_node1`), общаются между собой через транспортный слой; перед нодами — балансировщик haproxy (`tsk_http`).
- **Клиенты**: приложения и веб-интерфейс (ассеты dropwizard, отдаваемые веб-сервером `tsk_web_dev`), используют клиентскую часть фреймворка.
- **Хранилища**: состояние распределяется между узлами через Hazelcast; персистентность — MongoDB, Oracle, PostgreSQL или in-memory в зависимости от конфигурации запуска.
- **Внешние системы проекта (окружение)**: не описаны; детали — [плейбук окружения](../howto/project-environment/playbook.md) (будет дополнено по мере фиксации инструментов проекта).

## Границы
