# How-to: инверсный индекс (домен -> плейбуки)

Индекс строится по секциям «Зависимости (домены/компоненты)» каждого плейбука в `docs/howto/<slug>/playbook.md` и обновляется атомарно с ними. Изменение домена — повод перепроверить плейбуки, перечисленные в его строке.

| Домен | Плейбуки |
| --- | --- |
| metrics | [e2e-regression-run](e2e-regression-run/playbook.md) |

Плейбук [project-environment](project-environment/playbook.md) описывает инфраструктуру окружения и не зависит от доменов; остальные строки индекса — по секциям «Зависимости (домены/компоненты)» плейбуков.
