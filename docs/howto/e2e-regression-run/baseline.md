# E2E-регрессионный эталон (baseline)

## Назначение
Таблица зафиксированного результата регрессионного E2E-прогона
([плейбук](playbook.md)). Каждая новая сборка сопоставляется с эталоном:
регресс — ухудшение показателя относительно эталона при том же профиле прогона.

Правила обновления: эталон меняет лид по слову владельца после финального
прогона; значения «до» при обновлении переносятся в сравнительную таблицу
«показатель / до / после» и уходят в историю файла (git),
эталон — всегда текущий.

## Эталон: базовая (неизменённая) сборка

Сборка: образ `repository.technokad.ru:5000/taskurotta:12.5` (релизная, без правок).
Ключевое пространство e2e: 2184 method-ключа (363 актёра × 6 метрик + 6 агрегатных) + 367 number-ключей (queueSize 364 + memory 3).

| Показатель | Значение |
|---|---|
| Подсистема метрик, все хранилища (MAT, конец прогона, 164 мин) | 718.8 МБ (89% live-хепа 807 МБ) |
| DataPointVO | 17.02 M объектов (408.5 МБ) |
| Пик heap_used | 962 / 1024 МБ; OOME — нет |
| Корректность | 7471 стартов / 7466 завершено (99.93%); broken = 0; HTTP 5xx = 0 |
| Профиль | 363 актёра, профиль пика инцидента, ~2.7 часа нагрузки |

Вывод эталона: метрики — основной потребитель хепа (≥ 50% занятого),
рост 88.3 → 718.8 МБ за время прогона.

Происхождение:
- Дампы (5, конец — в таблице): sha-256: t15 `8c078076…`, t45 `6d98355c…`,
  t60-пик `812b6213…`, t120 `9eadcf1d…`, end `fc902142…`.

## Эталон: сборка с binning + purger

Сборка: локальный образ `taskurotta:12.6-e2e-003` (FROM
`repository.technokad.ru:5000/taskurotta:12.5` + COPY jar); jar
`taskurotta-12.6.jar` (42 242 222 B, sha256 `ab9dcdde…`), класс `DataRowVO`
sha256 `d44464e7…` (фикс накопления через оборот кольца). JVM/JDK без
изменений (1.8.0_66, -Xmx1024m).

Профиль и точки замеров — те же, что у эталона «до».

| Показатель | Значение |
|---|---|
| Подсистема метрик, все хранилища (MAT, конец прогона) | 44.1 МБ (MetricsDataHandler 40 492 488 B + NumberDataHandler 3 647 352 B; 34.6% live-хепа 127.6 МБ) |
| DataPointVO | 634 813 объектов (retained 22 166 912 B) |
| Пик heap_used | 476.5 / 1024 МБ (t = 9433 с, дренаж); OOME — нет |
| Корректность | 7471 стартов / 7467 завершено (99.95%); broken = 0; HTTP 5xx = 0; ERROR в service.log с t = 0 = 0 |
| Профиль | 363 актёра, профиль пика инцидента, ~2.7 часа нагрузки (как у «до») |

### Сравнение «показатель / до / после»

| Показатель | До (12.5) | После (12.6 + фикс) |
|---|---|---|
| Пик heap_used (Xmx 1024 МБ) | 962 МБ | 476.5 МБ |
| Подсистема метрик (MAT, конец) | 718.8 МБ (89% live-хепа) | 44.1 МБ (34.6% live-хепа) |
| DataPointVO | 17.02 M (408.5 МБ) | 634 813 (retained 22 166 912 B) |
| Число рядов (ключи) | 2184 method + 367 number | 2184 method + 367 number (плоское t45–end) |
| HTTP 5xx | 0 | 0 |
| Незавершённые процессы (state = 0) | 5 (артефакт дренажа) | 4 (артефакт остановки симулятора) |

Критерий регресса по памяти пройден: метрики ≤ 200 МБ — 44.1 МБ; хеп-пик
≤ 800 МБ — 476.5 МБ.

Происхождение:
- Дампы (5): sha-256: t15 `b24025c1…`, t45 `3b5b57c9…`, t60-пик `4ef8701b…`,
  t120 `2bedace8…`, end `b1f36731…`.
