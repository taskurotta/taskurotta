# How-to: Проектное окружение (project-environment)

## Назначение
Рецепт работы с окружением проекта (логи, базы данных, движок, трекер, локальные
среды). Описывает инфраструктуру окружения и не зависит от доменов.
Текущее состояние: без специфических инструментов — рецептур окружения проекта
пока не описано (оно появится по мере работы с проектом).

## Зависимости (домены/компоненты)
Нет (инфраструктурный плейбук, не зависит от доменов — см. `docs/howto/README.md`).
